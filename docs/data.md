# Data availability

## In this repository

All tables needed to reproduce the classification, the figures and every number in the documents are in [data/](../data/) (dictionary: [data/README.md](../data/README.md)), about 4 MB in total. The 62 input supercells are in [data/structures/](../data/structures/).

## Not in this repository

| Item | Size | Where it is identified |
|---|---|---|
| 320 MD trajectories (ASE `.traj`, 50 fs frames) | tens of GB | sha256 of every file in [data/provenance/trajectories.csv](../data/provenance/trajectories.csv) and in the task manifests |
| kinisi posterior samples (per run and window) | | regenerated by [src/ssemd/transport/kinisi_census.py](../src/ssemd/transport/kinisi_census.py) from a trajectory |
| MACE-MP-0 small model file | | sha256 in [provenance.md](provenance.md); public MACE-MP-0 release |

The trajectories are available from the author on request. To verify a copy, compare its sha256 with `trajectory_sha256` in `data/provenance/trajectories.csv`:

```bash
sha256sum census_12/p1r01_mp1097035/mace_600K.traj
```

## Regenerating raw data

[production/](../production/README.md) contains the MD runner and one manifest per batch. `python production/make_campaign.py production/manifests/def_b3.json <folder>` assembles a runnable campaign; with the same model, code, container and seed, an MD run reproduces the published trajectory up to GPU floating-point non-determinism. Analysis of a trajectory uses `ssemd.transport.kinisi_census.analyze_run` with the published settings.
